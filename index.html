Frequently asked questions

Are these image tools really free?

Yes. The browser-based convert, compress, resize and edit tools on ImageTools AI are free to use and do not require an account.

Do you upload my images?

Standard tools process files locally with the File, Canvas and Blob APIs. AI tools are separate: they send a resized image to our API only for that request, and only if AI is configured.

Which formats can I convert?

JPG, PNG and WebP conversions run in the browser. BMP and TIFF have dedicated conversion pages. Output is a newly encoded file, not a renamed extension.

Will this work on a phone?

Yes. The layout is built for 320px and up. You can pick images from the camera roll and download the result on the same device.
