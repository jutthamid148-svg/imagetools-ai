Smaller JPEGs without a desktop app

Each save of a JPEG can add artifacts, so start from the original camera file when you can. This page shows the new size before you keep the result. Use a quality around 70-85 for web photos, then drop maximum width to 1600 or 1920 if the picture is only going on a site.

Frequently asked questions

Should I compress a JPG that was already compressed?

You can, but quality falls each time. Prefer the original file.

Does EXIF stay in the file?

Canvas export writes pixels only, so metadata is not copied into the new JPEG.

Can I aim for a exact byte size?

No. You adjust quality and dimensions, then read the resulting size.

Is this local?
