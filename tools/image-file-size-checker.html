Bytes on disk, not pixels

      
File size is the number of bytes in the file you selected. Dimensions are separate. A huge pixel image saved as a high-quality PNG can be larger than a similar-looking JPEG. If the file is over a limit, open the compressor.

    

    

    
Frequently asked questions

    
Is this compressed size or pixel count?
The file’s byte size, plus dimensions in the meta row.
Does opening the file change the size?
No. Checking does not rewrite the file.
Why do two similar photos differ?
JPEG quality, resolution and noise all change byte size.
